# Writers expand a bounded repair into surrounding edits without a supported reason

Local ID: **CW-006**. Status: **OPEN**; exact edit application succeeds, preservation remains unqualified.

## Problem

Writers can repair the requested defect and retain required facts while also replacing adequate nearby prose. Keeping positive evidence quotations or using exact patches does not control which regions the writer selects or what it adds inside a replacement.

## Recorded evidence and attempts

Tests tried minimal-edit guidance, removing satisfied historical complaints, narrower boundary advice, positive fulfillment evidence, boundary framing, exact edits (E1), lower temperature and per-edit purposes. Some variants improved individual cases, but none established reliable edit selection.

One evidence replication avoided explicit restatement in all three evidence arms, yet all six writer outputs rewrote the ending. Lower temperature produced no clear preservation wins. With edit purposes, all twelve patches applied and all factual repairs succeeded; only four of eight purpose claims were fully supported. Identifying forbidden entry inside a sentence did not justify added imagery or edits to adjacent preparation.

Optional duplication controls also produced successful focused repairs. The problem is not an inability to edit precisely in every situation.

## Expected behavior and next investigation

Separate selecting a justified repair region from generating replacement prose. A bounded diagnostic could compare region selection against a supplied repair region, using saved cases plus fresh contexts. Include legitimate grammar dependencies and craft repairs inside fulfilled evidence; do not make cited sentences immutable. This is a proposal, not a prepared experiment.

## Closure criteria

- [ ] Repair the actual defect while accounting for every additional changed region with a supported task or dependency.
- [ ] Distinguish required repair, optional authorized craft and unsupported scope expansion using an unambiguous rubric.
- [ ] Preserve valid craft improvements and necessary adjacent changes; assess reader benefit separately.

The user reported nine literary ties across the reviewed pairs. These scope failures do **not** establish that the extra edits harmed the reading experience, and smallest diff is not the artistic objective.
