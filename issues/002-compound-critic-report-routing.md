# Ordinary critics cannot reliably report independent craft and boundary findings together

Local ID: **CW-002**. Status: **OPEN**, latest direct evidence 2026-10-17.

## Problem

Correctly noticing two defects does not guarantee a usable production critique. A duplicate sentence and a scene overrun require distinct reasoning, while the application owns boundary repair advice. Critics sometimes omit comparison references, author forbidden boundary conditions, or repeat a recommendation that should be reused. Strict validation correctly rejects these reports.

## Recorded evidence and attempts

Continuous prose plus the catalog (P1) improved raw duplicate detection from 0/4 to 4/4, but initially delivered only 2/4 valid duplicate findings. Both duplicate-plus-overrun cases exhausted their permitted correction. The duplicate itself remained correctly noticed.

A subsequent comparison delivered 3/4 valid supported duplicate findings. Expanded retry feedback recovered the same 2/3 rejected initials as ordinary feedback, adding no qualified recovery. In the remaining failure it supplied the missing comparison reference but introduced a model-written boundary condition instead. Shared native-condition consolidation is implemented; it did not resolve these compound output failures.

## Expected behavior and diagnostic case

Use the same scene in four forms: clean, accidental duplication only, overrun only, and both. Include intentional recurrence controls. The compound review must describe whether removing the boundary breach leaves an independent craft defect, cite the proper findings, and use each route's existing ownership rules.

## Closure criteria

- [ ] Deliver valid ordinary reports for compound cases while retaining the separate supported craft finding.
- [ ] Preserve application-owned boundary advice and shared native recommendations without duplicate authorship.
- [ ] Retain clean and functional-recurrence controls; report first-attempt and post-correction results separately.

Do not close this by deleting the craft finding, weakening validation, or counting an invalid raw observation as a usable critique. Semantic changes during correction are tracked separately in CW-003.
