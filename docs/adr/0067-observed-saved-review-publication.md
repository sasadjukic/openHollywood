# ADR 0067 — One observed saved-review delivery across exact artifact selections

Accepted on 2026-11-21 for the local Q008 operator publisher.

The original critique and its reviewed draft can each identify the same saved-review assessment. The observed generation attempt supplies its stable delivery ID. The request manifest records which artifact was selected when that attempt ran. Reopening the delivery through its associated draft preserves the original request, model response and generation usage.

For this registration, the operator publisher rebuilds both exact identities from the sealed source, audits the spent journal, binds the complete native work and verifies the observed audit, journal bytes and separately attributed score against their registered digests. The publication manifest lists both lookup selections in a fixed order. A single delivery record carries accounting. Retained transport envelopes and the evidence render supply its provenance.

The publisher uses the existing manifest-last writer. Both selection orders must create the same bytes and permit exact reuse. Ineligible inputs and conflicting destinations fail closed. The contract covers one registered observation and grants read-only operator access. Extending the consumer or artifact inspector requires a separate qualification. ## Second registration, 2026-11-22

Q013 qualifies under the same contract. The operator chooses one of two fixed registrations. Each identifies its own sealed source, original critique request, audited journal and independent score. Each manifest carries the registration's existing source identity and both exact selectors. The publisher preserves each scorer's original fields, including Q013's separate claim and evidence judgments. Both registrations' source directories are protected from publication writes. The original Q008 command continues to select Q008 exclusively. [Q013 implementation and replay](../handoffs/q013-observed-publication-2026-11-22.md)

## Shared operator lookup, 2026-11-22

The read-only operator lookup routes each exact selector to its independently pinned publication. Every refresh checks the original delivery, canonical manifest and complete publication before returning that assessment. Lookup rows reference assessments by delivery and claim, and accounting records by delivery. Publication failure affects only the matching rows. The Q008-only command retains its original contract for existing callers, including the artifact inspector. [Consumer qualification](../handoffs/q008-q013-consumer-lookup-2026-11-22.md)
