# ADR 0060: Registered observed completion over authored sources

- Status: Accepted; bounded read-only local implementation
- Date: 2026-11-15
- Extends: ADRs 0056–0059

## Decision

Add a separate application publisher and operator CLI for the three saved authored
smoke deliveries. Register only `authored-smoke-2026-11-15`, pinning the exact plan
and original seventeen-member audit manifest. The caller selects that registration
and an output directory; there is no receipt, origin, trust-path, hash or work-subset
override. Keep the authored-fixture and registered-probe publishers unchanged.

Reauthenticate the complete existing audit through its supported entry point and
require exact reuse. Reconstruct all three terminals and whole-work completions
from the original sources, request manifests and six endpoint outcomes. Require
observed transport/model evidence, complete journal closure, every original work
and slot, all four usage counters known, no accounting hold and no budget violation.
A valid native receipt or positive eligibility boolean alone cannot authorize
publication. Refuse the complete publication if any work fails admission.

Keep `source_origin=authored_diagnostic` separate from
`delivery_origin=observed_openai_transport`. Preserve each complete `AuthoredSource`,
its six byte-exact input members and construction receipt, exact request and
presentation, terminal, endpoint outcomes and native completion. Original local
scope and authority stay unchanged. Derive request-bound rendering authority into
a separate retained value. Do not manufacture saved-review intake provenance.

The native authority view uses the bound terminal receipt, matching the reference
audit. Its explanatory header links the full completion envelope and identifies the
view as a projection. Native result field names and successful literal binding do
not authenticate origin or qualify semantic judgments by themselves.

## Publication and limits

Reuse existing bounded reads, secret refusal, link/junction checks, bidirectional
source/output protection, exclusive writes, manifest-last finalization and exact
byte reuse. Protect sources, request preparation, plan, gold, metadata, closed
journal and reference audit. Recheck source membership/content and implementation
after rendering, before writes/finalization and on reuse. Preserve partial failed
outputs without repair or overwrite. A final manifest is the completion marker.

The export has 43 files: thirteen per family, three shared audit/request files and
one final manifest. Both full envelopes and the manifest retain unassessed semantic
support, evidence adequacy, editorial effect, edit necessity and craft; writer
permission is false. All observed token counters remain visible. Actual billed
cost is unknown. `live_calls=0` describes this local publication, not the historical
six endpoint calls recorded by the retained observation.

The application-owned journal is not provider-signed attestation. This adapter adds
no transport, database writes, route, UI, migration, dependency, prompt change or
workflow decision. A new engine evaluation module would change frozen source
fingerprints, so reuse existing domain records from this separate application
adapter. Tests use synthetic captures; qualification additionally replays all three
registered saved observations without inference.

See the [implementation report](../handoffs/assessment-authored-observed-completion-2026-11-15.md)
for verification and the next consumer boundary. Live calls remain paused and the
workflow canary remains on hold.
