## Limits preserved by the regressions

The application does **not** infer semantic truth from structural completion.
A deliberately incorrect free-text obligation can satisfy the structural schema;
the preview still marks semantic interpretation unverified and cannot authorize
writer dispatch. Similarly, a real, bindable quotation can be insufficient for a
claim about the complete earlier scene. Evidence binding remains distinct from
evidence adequacy, whole-claim support, edit necessity and craft.

The new tests also cover changed request/final/source identity, incomplete scope
or authority, missing historical bodies, unknown visibility, incorrect source roles,
stale receipts, H presented as B, literal-render escaping, gold exclusion, export
provenance rejection, path escape, conflicting outputs and secret checks before
writing. Failed delivery cannot be salvaged into a successful result. Generic
native completion preserves unknown usage explicitly; this does not relax the
completed live comparison's stricter known-usage stop rule.

## Export and integration gap

The static audit found no external imports of the five assessment components in
**115 other application/engine/script Python files**. They are currently pure
read-only components, with no supported native archive-export CLI or production
caller. This is a static import and path audit, not a proof about hypothetical
dynamic code.

requires real successful `scene_critic` database lineage, ordinary v61/schema7/graph9
and its linked critique artifact. A native diagnostic assessment does not qualify.
The separate [probe exporter](../../apps/api/open_hollywood_api/services/probe_review_export.py)
is registered to its October 16 probe archive and trial contract. It also does not
admit these B/H captures. Neither contract should be silently broadened or have its
provenance manufactured to accommodate this archive.

The private audit adapter demonstrates that the existing renderer can serve this
archive. **Rendering is locally verified; supported operator delivery is not yet
implemented.** No canonical story artifact or application database was modified.
