## P: diagnose endorsement/framing sensitivity with logical complements

Retain **N and U** in full: both have an unambiguous false factual-contradiction
claim, a real requirement violation and supported characterization criticism.
Add two fresh families: one with a **genuine same-event factual contradiction**,
and one where **the relation is unresolved because identity/time is insufficient**.
Use different settings and event structures, not renamed floodgates or heaters.
Keep grounded requirement/craft controls alongside each target.

For each case, CV assesses its original three claims. CP changes only C02 to the
logical negation of that complete relation assertion; the other two claims,
sources, ordering, interface, instructions, output schema and sampling stay the
same. The four inherited CV wire payloads must remain byte-identical to their
archived equivalents. CP is a request-content contrast, not a longer explanation
prompt, another component layout or a stronger model.

Preparation must verify the logical complement carefully: preserve the exact
relation arguments, subject, time, version, quantifiers and modality. Do not
substitute a corrected event fact, swap status for resolve, or weaken a compound
claim. Genuine uncertainty must remain uncertainty under either polarity. If a
fresh case cannot support an unambiguous complement and gold, revise it locally
before freezing. Gold, complementary answers, historical outcomes and audit
rationales remain hidden from each request.

This tests a different question from CA's explicit component instructions and
MC's premise-assessment instruction: **does judgment change when the identical
relation is asserted with the opposite truth polarity?** It is not sufficient
for CP to endorse the now-true compatible-case target. An always-supported
response would then fail the genuine-contradiction family's negated target.

Report raw labels before applying any comparison mapping. To compare the same
underlying relation, invert supported/unsupported for CP's target; leave
uncertain unchanged. Map only for analysis, never rewrite the captured answer
or the adjudication standard. Compare complete reasons against the assertion
actually given, and inspect all source passages. Correctly repeating both
events is still insufficient to justify their asserted relation.

Report target results in four categories: both formulations correct, only CV
correct, only CP correct, neither correct; report abstention, invalid delivery
and terminal attempts separately. Explicitly count endorsements of both mutually
exclusive assertions. A CP improvement on these *different assertions* is a
formulation-sensitive result, **not a same-claim repair or semantic recovery**.

Provisional evidentiary screen:

- At least **7/8 valid CP reports**, with no loss of valid CV delivery; require
  valid delivery in all fresh cells for the following semantic conclusions.
- For a repeatable compatibility-case framing signal, require CP's grounded,
  normalized correctness where CV is wrong in **both N and U, both orders**.
- Require correct grounded target judgments in **both orders of each fresh
  family**, including unsupported on the negation of a true contradiction and
  uncertainty where the source cannot settle the relation. Retain all usable
  requirement/craft controls and reason/citation support.

If the first signal appears but the polarity or uncertainty controls fail, report
that limitation rather than a usable verifier. If N/U control failures disappear,
record insufficient diagnostic opportunity. If both formulations endorse their
opposite claims, that establishes inconsistent acceptance on these paired
requests; it does not prove the model's internal mechanism. In every outcome,
do not deploy a negated-claim gate or add a production second call.
