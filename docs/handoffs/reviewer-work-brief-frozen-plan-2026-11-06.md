whole proposition and cite its material evidence without substituting a question

body repeats.** Each request assesses six whole fields: **18 unique claims / 144

`high`, the preceding U instructions, output contract, adapter and resource limits.

| Condition | Exact difference |
| --- | --- |
| U | The unchanged generic U system instructions, full sources/report and whole admitted spans; no per-claim brief. |
| B | The same request, with `assessment_work_brief` added to the selection message. Each item binds an existing field ID to a question, temporal scope, source authority and evidence obligation. |

Removing that one JSON member from B must reproduce U's entire generation body.
There is no system-prompt amendment, model change, schema change, cropped context,
extra evidence, expected answer or example citation in B. Its exact questions are
author-reviewed to avoid presupposing an obligation, occurrence or violation.
The binding validator checks the frozen shape/text; it cannot prove arbitrary
wording neutral or semantically correct.

For example, the brief attached to “Elena must decide to verify the handwriting”
asks **“Does the assignment impose the quoted requirement?”** and states that
fulfillment and further repair are separate questions. It supplies neither the
answer nor the assignment's location. Existing admitted spans already contain the
whole quotation, so briefs bind by field ID without duplicating it.

PC presents prose before surrounding context; CP reverses these blocks. All
sources remain complete. Each condition/order's second generation and count
bodies are byte-equivalent under the frozen canonical JSON encoding to its first.
The two conditions run adjacent within each family/order; which runs first is
counterbalanced and reversed in repeat two. This controls ordering without claiming
independent samples or statistical power from repeated slots.

## Evidence and scoring

Keep the preceding **section-locator** contract. Each exact, unique quote addresses
one immutable field or one prose paragraph; its whole containing section is the
evidence unit. Adjacent uncited paragraphs receive no citation credit. Each claim
allows up to **8 distinct witnesses**, quotes of 1–512 characters and a reason of
1–1,200 characters; total witness text ≤8,000, total reasons ≤8,000 and final output
≤64,000 characters. Empty evidence is permitted only for `uncertain` with an
adequate missing-source explanation. Native strict structured output is retained.

Inspect all 144 fixed slots against the frozen whole claim, material components,
reason and actual source sections:

1. **Unavailable:** missing, undispatched or invalid delivery; retain the slot.
2. **Semantic failure:** wrong label, materially incorrect explanation or answering
   a substituted/partial question. Correct labels alone do not pass.
3. **Citation-only failure:** semantics pass, but a witness is unresolved or cited
   sections do not cover material claim/reason premises.
4. **Grounded:** correct whole-claim semantics, binding and adequate evidence.

Illustrative witness sets are **not a whitelist**. Accept genuinely adequate
alternatives after full-context inspection. A positive occurrence can establish
an interval violation without an ending citation; endpoint-state claims need
appropriate terminal evidence. Whole-scene absence requires relevant interval
coverage or an adequate explicit interval statement. Any additional material fact
in a reason, including an ending qualification, needs its own cited coverage.
Ancillary concessions are logged separately; no retrospective gold repair.

Report per-claim four-slot results, each condition/cohort/predicate, **72 U/B
pairs**, **72 repeat pairs** and **72 order pairs**. Stable wrong answers fail.
The positive brief screen requires **all 72 B slots grounded**, at least one
matched semantic/citation U failure recovered in B, and **zero U-grounded/B-failing
pairs**. An unavailable U is not a recovery. If both conditions pass everything,
report a ceiling result, not evidence of B's advantage. Any missing B slot fails
its claim's four-slot gate. No causal/population inference is authorized by this
small screening design.

Record latency, count/generation requests, input, cached input, generated and
reasoning tokens, terminal errors and reference cost by condition. Report brief
overhead alongside accuracy; identical output wording/citation choices are not
required. Mechanical completion still confers no factual or writer authority.
