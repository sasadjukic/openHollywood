## Minimal consumer contract

This is a proposed application projection, exercised privately rather than installed
as a new engine contract. Reuse the native records and the two registered publishers.

| Information | Required behavior |
| --- | --- |
| Authentication | Select a fixed publication registration. Verify its exact manifest/membership and require supported publisher reauthentication with exact reuse. A caller-provided hash, result or origin label is not authority. |
| Identity | Namespace each field/unit by registration, publication digest, work digest, exact request digest and field pointer. Repeated `Q001` IDs and identical words across works must not join records. |
| Original review | Retain every original field and whole selected statement unchanged. Keep the original intake disposition alongside the later delivery state. |
| Model judgment | Display support label and reason explicitly as model-reported. Keep the raw final and complete envelope accessible. Never overwrite the original criticism. |
| Evidence | Carry exact document/version/field/offset/quote bindings. Distinguish complete-field spans from located sections. Both remain semantically unassessed. |
| Cardinality | Reuse the native rule: supported/unsupported judgments need at least one citation; uncertain judgments may have none. Citation presence is not semantic sufficiency. |
| Claim obligations | Retain the authored whole-claim components, source roles, temporal scope and work brief. An obligation being specified does not mean the model supplied adequate evidence for it. |
| Authority | Authored packets have a separate request-bound authority record. Probe completions retain declarations/work briefs but do not supply that additional record. Show the difference; do not fabricate or import historical authority. |
| Delivery and accounting | Keep source origin and delivery origin distinct; retain all four usage counters and null actual billing. Refuse successful interpretation of missing, failed, partial, stale or accounting-held data. |
| Semantic/editorial status | Preserve unassessed support, evidence adequacy, editorial effect, edit necessity and craft. Keep writer permission false and whole-review verdict absent. |
| Production association | Preserve null canonical review/artifact-version association. A diagnostic capture identifier or text match is not a production artifact binding. |

For successful observations, the private prototype uses
`observed_bound_unassessed`. Selected fields without an admissible result display
`assessment_unavailable`, retaining their original text and selection. Held and
unselected fields retain those statuses. A missing or duplicate expected work makes
the catalog inventory incomplete. Completing the inventory does not create a review
verdict. Explicitly authored counterfactuals carry their own origin and receive no
new observed-model credit.

The five delivered `uncertain` judgments remain available model assessments. They
are distinct from `assessment_unavailable`, which carries no model judgment.
Missing source content and missing assessment delivery must not share one status.

Full sources, exact requests and native result envelopes are available through local
artifact links. Model text is rendered literally; model-provided Markdown or URLs
cannot create navigation. The private view is an inspection artifact, not a proposed
requirement that humans read or mechanically score all 63 fields.

## Production integration audit

All seven native contexts have `canonical_review_id=null`. The inspected exports
do not provide a qualified association to a production artifact-version UUID.
Their source hashes and request bindings establish diagnostic provenance, not that
association. No user database was opened to guess or manufacture a mapping.

The current [ArtifactInspector](../../apps/web/src/components/ArtifactInspector.tsx)
shows immutable selected artifact content and version context. Its generic content
renderer and [ArtifactVersionDetail](../../apps/api/open_hollywood_api/workspace_models.py)
do not define this consumer projection. The existing evaluation summary is a
different contract; putting these model labels into its scores or artifact status
would erase the distinctions this rehearsal preserves. No such integration was made.

The four probe completions retain their original `pending_assessment` intake
dispositions even though delivery is now complete. Those are two stages of the
same record, not an inconsistency to repair by modifying the immutable intake.
Likewise, authored construction receipts remain local construction evidence; the
outer observed-delivery binding supplies the later assessment provenance.
